Opening prompt

How many Player objects exist after Player b = a if a already refers to one Player?

September 17, 20262 / 9

Key ideas

new creates an object and returns a reference to it.

Assigning an object variable copies a reference.

A method call can change an object that several variables reach.

September 17, 20263 / 9

Worked example

Player a = new Player("Mira", 2);
Player b = a;
b.addScore(3);
b = new Player("Sol", 8);
System.out.println(a.getScore());
September 17, 20264 / 9

Reasoning

Both references initially reach the same Player, so addScore changes its score to 5. Reassigning b makes it reach a new object. It does not change a, and the printed value is 5.
