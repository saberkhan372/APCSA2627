Shopping Cart: build

Compute a cart total from objects stored in a typed list.

January 28, 2027

January 28, 20271 / 9

Opening prompt

An item costs 2.50 and quantity is 3. What is its contribution to the cart total?

January 28, 20272 / 9

Key ideas

A list of Item references stores access to each item’s state.

Quantity contributes to a line total through multiplication.

Getters let an aggregate observe objects without duplicating their representation.

January 28, 20273 / 9

Worked example

double total = 0.0;
for (Item item : cart) {
    total += item.getPrice() * item.getQuantity();
}
January 28, 20274 / 9

Reasoning

The accumulator represents the sum of all line totals already visited. An empty cart gives total 0.0 in this example. Getter names must match the provided Item class.

A common error
