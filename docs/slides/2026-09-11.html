September 11, 20261 / 9

Opening prompt

Predict the value and type of 9 / 4, 9 / 4.0, and (double)(9 / 4).

September 11, 20262 / 9

Key ideas

Integer division discards the fractional part toward zero.

Cast an operand before division when a fractional answer is needed.

Assignment stores the result after the expression has already been evaluated.

September 11, 20263 / 9

Worked example

int total = 9;
int count = 4;
double first = total / count;
double second = (double) total / count;
int remainder = total % count;
September 11, 20264 / 9

Reasoning

first stores 2.0 because 9 / 4 produces integer 2. second stores 2.25 because the cast changes an operand before division. The remainder is 1, satisfying 9 = 4 * 2 + 1.
