Opening prompt

Which proposal is easier to test: "make a weather app" or "summarize valid daily temperatures from a cited file"?

May 14, 20272 / 9

Key ideas

A useful proposal names a user and a question or task.

The smallest version should produce a complete result.

Optional features should not obscure the required behavior.

May 14, 20273 / 9

Worked example

Example scope:
User: a reader comparing daily temperatures
Input: a documented text file
Required result: mean of valid readings and their count
Limit: one location and one unit
Optional later: a second group comparison
May 14, 20274 / 9

Reasoning

This proposal reuses known parsing and aggregation skills while defining a complete minimum result. It also limits the claims the program can make about its data.
