HotelRoom: scope and this

Resolve shadowed field names with this.

November 19, 2026

November 19, 20261 / 9

Opening prompt

Inside setFloor(int floor), what does the bare name floor refer to?

November 19, 20262 / 9

Key ideas

A parameter can shadow an instance field with the same name.

this identifies the current object.

A precondition states what the caller must ensure before a method runs.

November 19, 20263 / 9

Worked example

public void setFloor(int floor) {
    this.floor = floor;
}
// this.floor is the current object’s field.
// floor on the right is the parameter.
November 19, 20264 / 9

Reasoning

The assignment copies the argument value into the current object’s field. Writing floor = floor assigns the parameter to itself and leaves the field unchanged.

A common error

Do not add this to a local variable or use it from a static method. this identifies an instance.
