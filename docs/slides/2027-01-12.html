January 12, 20271 / 9

Opening prompt

Two lines contain 2 values and 4 values. Is dividing the total by 2 a mean over all six observations?

January 12, 20272 / 9

Key ideas

A sum and a count must describe the same set of values.

Line boundaries can represent groups such as weeks.

A maximum needs initialization compatible with all permitted temperatures.

January 12, 20273 / 9

Worked example

double[] readings = {-4.0, 2.0, 8.0};
double sum = 0;
double maximum = readings[0];
for (double value : readings) {
    sum += value;
    if (value > maximum) { maximum = value; }
}
double mean = sum / readings.length;
January 12, 20274 / 9

Reasoning

The sum is 6.0, the mean is 2.0, and the maximum is 8.0. Initializing maximum to zero would fail for an all-negative dataset.
