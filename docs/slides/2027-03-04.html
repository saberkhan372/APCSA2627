Opening prompt

If low = 0, high = 6, mid = 3, and values[mid] is below the target, what interval is passed next?

March 4, 20272 / 9

Key ideas

Recursive binary search preserves the same sorted-interval invariant as its iterative version.

Merge sort divides a collection and then combines sorted halves.

A merge needs ordered inputs before it can select the next smallest value.

March 4, 20273 / 9

Worked example

Input: [7, 2, 6, 1]
Split: [7, 2] and [6, 1]
Sort halves: [2, 7] and [1, 6]
Merge: 1, then 2, then 6, then 7
March 4, 20274 / 9

Reasoning

At each merge step, compare the next unused value from each sorted half. Once one half is exhausted, append the remaining ordered values from the other.

A common error

Splitting a collection does not sort it. The merge stage relies on recursive calls having already sorted the halves.
