Duck design and BandBooster launch

Design fields and methods around an object’s responsibilities.

November 9, 2026

November 9, 20261 / 9

Opening prompt

A booster has a name and a sales total. Which facts vary per booster, and which actions change those facts?

November 9, 20262 / 9

Key ideas

Instance fields represent the state each object must remember.

Public methods describe the allowed interactions.

A class model includes only information needed for its purpose.

November 9, 20263 / 9

Worked example

public class Meter {
    private int total;
    public Meter() { total = 0; }
    public void add(int amount) { total += amount; }
    public int getTotal() { return total; }
}
November 9, 20264 / 9

Reasoning

Meter stores one fact and offers controlled ways to change and observe it. The constructor establishes the initial value. The getter returns information that any caller can use.
