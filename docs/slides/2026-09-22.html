Key ideas

Character indexes run from 0 through length() - 1.

substring(start, end) includes start and excludes end.

String methods return values. They do not change the original String.

September 22, 20263 / 9

Worked example

String word = "planet";
String middle = word.substring(1, 4);
int position = word.indexOf("x");
String unchanged = word;
September 22, 20264 / 9

Reasoning

middle is "lan" and position is -1. word still contains "planet". A failed search result must be handled before it is reused as an index.

A common error

An end index equal to length() is legal for substring. A character index equal to length() is outside the String.
