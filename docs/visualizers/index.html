Visualizers

Step through what Java actually does. Each tool starts with a prediction, so commit to an answer before you look.

  • compareTo Visualizer

    Pilot

    Watch Java compare two Strings one index at a time, stop at the first mismatch, and fall back to length when one string is a prefix of the other.

  • String Index Explorer

    New

    Boxes for charAt, fence posts for substring, a sliding search for indexOf, and a line-by-line tracer for the WorkingWithStrings lab.

  • Expression and Type Tracer

    Coming next

    Precedence, integer division, %, casting and left-to-right String concatenation.

  • Memory Diagram

    Planned

    References, aliasing, == versus .equals, and why Strings never change.

  • Math.random Range Builder

    Planned

    Build (int)(Math.random() * (max - min + 1)) + min one step at a time.

  • Output Predictor

    Planned

    print versus println and escape sequences.

How to use them: Predict first, with a reason. Then use Explore to test your own examples. Finish with Transfer, which has no animation, to check you can do it on paper.
