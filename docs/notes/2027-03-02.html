Recursion call-stack tracing

Trace separate recursive calls and their returned values.

Open slidesDaily assignmentDownload notesRecursion Call Stack

Key ideas

  • Each call has its own parameter and local-variable values.
  • The base case supplies a result without another recursive call.
  • Return order reverses the path of pending calls.

Opening prompt

For sumTo(3), what calls occur before the first return if sumTo(0) is the base case?

Worked example

public static int sumTo(int n) {
    if (n == 0) { return 0; }
    return n + sumTo(n - 1);
}

sumTo(0) returns 0, then the pending calls return 1, 3, and 6. The n in each addition belongs to that call’s own frame. Assume n is nonnegative.

Practice

Predict supplied RecursionTrace methods before running them. Track call order, local values, pending work, and return order. Compare printing before and after a call.

Common error

A recursive call does not change the caller’s local n. It receives its own parameter value.

Exit check

Which two features must you identify before tracing a recursive method?

Turn in

Call-stack diagrams and predicted output; RecursionTrace checks.
