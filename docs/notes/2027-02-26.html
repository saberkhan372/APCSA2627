Selection and insertion sort

Trace selection-sort passes and insertion-sort shifts.

Open slidesDaily assignmentDownload notes

Key ideas

  • Selection sort places a selected minimum into the next settled position.
  • Insertion sort inserts one value into the already-sorted prefix.
  • A temporary variable protects a value while other elements shift.

Opening prompt

After the first selection-sort pass on [4,2,3,1], what is guaranteed?

Worked example

Initial:             [5, 1, 4, 2]
Selection pass 1:    [1, 5, 4, 2]
Selection pass 2:    [1, 2, 4, 5]
Insertion pass 1:    [1, 5, 4, 2]
Insertion pass 2:    [1, 4, 5, 2]

The two algorithms can have identical early states but different next passes. Selection settles the next smallest remaining value. Insertion maintains a sorted prefix containing the values seen so far.

Practice

Use SortTrace to follow each comparison, selected index, and shift. Compare already-sorted and reverse-ordered inputs.

Common error

Do not confuse a temporarily held insertion value with a value that has been lost from the array.

Exit check

What region is sorted after insertion sort has finished the pass that inserts index k?

Turn in

SortTrace checks; one pass table for each algorithm; invariant explanation.

After class

20 min: complete one fresh trace of each sort; record comparisons versus swaps/shifts.
