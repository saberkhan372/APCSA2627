Selection and iteration synthesis

Repair a control-flow error and demonstrate transfer to a new input.

Open slidesDaily assignmentDownload notesLoop TracerBoundary-Case TesterLoop Construction WorkbenchBoolean and Short-Circuit Explorer

Key ideas

  • A test should distinguish the incorrect algorithm from the intended one.
  • The smallest failing input often exposes the cause clearly.
  • A repair needs a fresh check after the original failure passes.

Opening prompt

Quick diagnostic: negate p && q; count iterations for i = 0; i < 5; i += 2; give the bound for reading index i + 1; count an inner body with three outer iterations and four inner iterations each.

Worked example

int matches = 0;
for (int i = 0; i + 1 < text.length(); i++) {
    if (text.substring(i, i + 1)
            .equals(text.substring(i + 1, i + 2))) {
        matches++;
    }
}

This example counts overlapping equal adjacent pairs. "aabb" gives 2 and "aaa" gives 2. Its contract differs from counting non-overlapping doubles.

Practice

Use the diagnostic to select Boolean equivalence, loop bounds, String scans, or nested-loop counts. Finish the relevant Feeder or project repair, explain the rule, then solve a fresh case independently.

Common error

Do not switch between overlapping and non-overlapping interpretations while evaluating the same method.

Exit check

Give one input that distinguishes overlapping pair counting from non-overlapping counting.

Turn in

Working runner; six mixed retrieval answers; one oral explanation.

After class

25 min: revise the Unit 2 error log and rehearse two method skeletons.
