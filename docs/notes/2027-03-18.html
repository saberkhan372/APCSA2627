Cumulative pre-break baseline

Use a cumulative baseline to choose specific April priorities.

Open slidesDaily assignmentDownload notes
Complete the independent attempt before using the worked review example. Your teacher supplies the selected assessment questions.

Key ideas

  • Independent predictions reveal current understanding.
  • Classify errors by the concept that caused them.
  • Choose practice that targets the cause rather than repeating every topic equally.

Opening prompt

Prepare the 21-item set, reference materials, and an error-log page. What will you record after the timed attempt?

Worked review example

Error-log example:
Topic: substring boundaries
Mistake: included the end index
Correct rule: end is excluded
Next task: predict three slices, including an empty slice

A useful priority names a specific decision the student will improve. "Review Strings" is too broad to identify which practice would help.

Practice

Complete 21 fresh MC items in 45 minutes. Use 30 minutes to classify mistakes and choose two April priorities.

Common error

An error category should describe the cause, not merely the question number or "carelessness".

Exit check

Name two April priorities and the first concrete practice task for each.

Turn in

Baseline responses; correction plan; list of uncertain Java behaviors.

After class

Optional, at most 40 min over spring break: redo four misses and one short method. No new content or required break packet.
