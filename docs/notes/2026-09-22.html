String Activity and WordTools

Use String indexes and substring boundaries safely.

Open slidesDaily assignmentDownload notes

Key ideas

  • Character indexes run from 0 through length() - 1.
  • substring(start, end) includes start and excludes end.
  • String methods return values. They do not change the original String.

Opening prompt

For "planet", what does substring(1, 4) return? Is substring(6, 6) valid?

Worked example

String word = "planet";
String middle = word.substring(1, 4);
int position = word.indexOf("x");
String unchanged = word;

middle is "lan" and position is -1. word still contains "planet". A failed search result must be handled before it is reused as an index.

Practice

Draw indexes for "red kite". State how firstWord should behave with a space, with no space, and with an empty String. Match safeSlice to its supplied contract.

Common error

An end index equal to length() is legal for substring. A character index equal to length() is outside the String.

Exit check

State the legal relationship among start, end, and n for substring(start, end).

Turn in
