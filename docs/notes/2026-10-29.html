Methods checkpoint: Feeder

Translate a method specification into branches, random ranges, and state updates.

Open slidesDaily assignmentDownload notes
Complete the independent attempt before using the worked review example. Your teacher supplies the selected assessment questions.

Key ideas

  • Read the full method contract before coding.
  • A random choice and a random quantity may require separate samples.
  • A state update must respect limits such as available capacity or stock.

Opening prompt

For an unrelated supply model, need is 12 and available stock is 7. How much stock can be used?

Worked review example

int available = 7;
int requested = 12;
int used = requested;
if (used > available) { used = available; }
available -= used;

This original supply example caps consumption at the available amount using selection. It leaves available equal to zero. Follow Feeder’s own specification for its probabilities and food calculation.

Practice

Attempt released 2024 Feeder part (a) independently for 20 minutes. Afterward, annotate the branch, range calculation, and field update in your own response.

Common error

Do not reuse one random sample for unrelated decisions unless the specification explicitly defines that dependence.

Exit check

Name one boundary case that a plausible random simulation could miss.

Turn in

Timed method, annotated correction and normal/boundary tests.

After class
