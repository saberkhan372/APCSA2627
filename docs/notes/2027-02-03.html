2026 FRQ 3: Attendance

Compare two lists while preserving the specified inputs.

Open slidesDaily assignmentDownload notes
Complete the independent attempt before using the worked review example. Your teacher supplies the selected assessment questions.

Key ideas

  • Read whether a method may mutate its arguments.
  • Comparing every candidate may require a nested traversal.
  • Duplicates and matching criteria come from the contract.

Opening prompt

If a method’s contract says neither input list changes, is removing matched elements from a list a valid shortcut?

Worked review example

ArrayList<String> left = new ArrayList<String>();
left.add("red");
left.add("blue");
ArrayList<String> right = new ArrayList<String>();
right.add("blue");
boolean same = left.get(1).equals(right.get(0));

same is true and neither list changes. A matching algorithm can record a Boolean or count while keeping the original collections intact. Whether one match or every match counts depends on the exact specification.

Practice

Attempt released 2026 Attendance for 23 minutes. Then trace cross-list matches and compare both input lists before and after the method.

Common error

A correct numeric result does not excuse an unrequested mutation.

Exit check

What test evidence would show that your method preserved both lists?

Turn in

Timed method; corrected method; cases for matching and nonmatching IDs.

After class

20 min: explain nested-list traversal and one missed case.
