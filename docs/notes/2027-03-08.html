Key ideas

  • A 2D method must use the correct bound for each index.
  • Search and sort reasoning depends on a stated invariant.
  • Recursive tracing distinguishes call order from return order.

Opening prompt

Worked review example

// After submission: unrelated 2D review
int negatives = 0;
for (int r = 0; r < grid.length; r++) {
    if (grid[r][column] < 0) { negatives++; }
}

The sample counts negative values in one fixed column, assuming that column is valid in every row. Its bound is the number of rows because r changes.

Common error
