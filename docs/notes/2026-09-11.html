ExpressionLab and Circle

Predict numeric types and preserve precision in an average.

Open slidesDaily assignmentDownload notes

Key ideas

  • Integer division discards the fractional part toward zero.
  • Cast an operand before division when a fractional answer is needed.
  • Assignment stores the result after the expression has already been evaluated.

Opening prompt

Predict the value and type of 9 / 4, 9 / 4.0, and (double)(9 / 4).

Worked example

int total = 9;
int count = 4;
double first = total / count;
double second = (double) total / count;
int remainder = total % count;

first stores 2.0 because 9 / 4 produces integer 2. second stores 2.25 because the cast changes an operand before division. The remainder is 1, satisfying 9 = 4 * 2 + 1.

Practice

Repair average in ExpressionLab. For Circle, use radius 3.0 and Math.PI to compute area and circumference. Read the radius with Scanner.nextDouble().

Common error

A double destination does not undo integer division. Ask students to label the type of each intermediate expression.

Exit check

Why does double x = 5 / 2 store 2.0? Give the smallest change that stores 2.5.

Turn in

ExpressionLab checks; value/type table; explain why double x = 7/2 loses the fraction.
