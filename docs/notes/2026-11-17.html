Ticket static state

Distinguish class-wide state from each object’s state.

Open slidesDaily assignmentDownload notes

Key ideas

  • A static field belongs to the class.
  • Each object has its own instance fields.
  • A static method needs an object reference to access a particular instance’s fields.

Opening prompt

Three Ticket objects have their own id values but share nextId. How many nextId fields exist?

Worked example

public class Badge {
    private static int nextId = 1;
    private int id;
    public Badge() {
        id = nextId;
        nextId++;
    }
}

The first three constructed Badges receive ids 1, 2, and 3. Afterward nextId is 4. Advancing shared nextId does not overwrite ids already stored in earlier objects.

Practice

Complete Ticket and trace three constructions. Connect each field in Counting Transactions to either one account/object or the shared class state.

Common error

Making every field static may silence an access error while changing the meaning of the program.

Exit check

Should getBalance be static if it returns one account’s balance? Why?

Turn in

Ticket checks; two-object trace; static-versus-instance explanation.
