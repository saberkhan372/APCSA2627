Weather Data Analyzer and parsing

Compute file-based weather aggregates with the correct denominator.

Open slidesDaily assignmentDownload notes

Key ideas

  • A sum and a count must describe the same set of values.
  • Line boundaries can represent groups such as weeks.
  • A maximum needs initialization compatible with all permitted temperatures.

Opening prompt

Two lines contain 2 values and 4 values. Is dividing the total by 2 a mean over all six observations?

Worked example

double[] readings = {-4.0, 2.0, 8.0};
double sum = 0;
double maximum = readings[0];
for (double value : readings) {
    sum += value;
    if (value > maximum) { maximum = value; }
}
double mean = sum / readings.length;

The sum is 6.0, the mean is 2.0, and the maximum is 8.0. Initializing maximum to zero would fail for an all-negative dataset.

Practice

Complete WeatherData using the corrected W46 starter. Read each weekly line, split the numeric text, parse values, and compute weekly means and the overall maximum.

Common error

An average of weekly averages is not an overall observation mean when groups have different counts.

Exit check

What two accumulators are needed to average only positive readings?
