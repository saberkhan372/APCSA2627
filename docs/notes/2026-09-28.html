Unit 1 retrieval and repair

Use a mixed trace to identify the next concept to repair.

Open slidesDaily assignmentDownload notesString Index ExplorercompareTo Visualizer

Key ideas

  • A prediction should name both the result and the rule used.
  • Categorizing errors helps choose useful practice.
  • A successful repair must also work on a fresh input.

Opening prompt

Which rule is at risk in each expression: 7 / 2, a == b, and text.substring(2, 5)?

Worked example

double average = 11 / 4;
String text = "robot";
String part = text.substring(1, 4);
boolean match = part.equals("obo");

average stores 2.0, part is "obo", and match is true. Trace expressions before assignments and check substring boundaries before naming the selected text.

Practice

Predict all six Unit1Review results, then run the checks. Choose two error categories and solve a new example in each before the AP Classroom set.

Common error

Correct answers produced by running code first do not show that a student can trace independently.

Exit check

Write one error you repaired and one new input that would expose it again if it returned.

Turn in

Review checks; eight MC responses; personal two-item error log.

After class

25 min: rehearse casts, method calls and String indexes; rewrite two corrected examples.
