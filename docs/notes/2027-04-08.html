int split = code.indexOf("-");
String prefix = code.substring(0, split);
String suffix = code.substring(split + 1);

For the illustrated input, prefix is "AB" and suffix is "42". If a separator is not guaranteed, a method must handle an indexOf result of -1 before slicing. Follow the actual Account preconditions.
