String Output Lineup and StringRelations

Choose equality or ordering according to the String question.

Open slidesDaily assignmentDownload notescompareTo Visualizer

Key ideas

  • equals compares String contents.
  • == compares whether two references identify the same object.
  • compareTo supplies a negative, zero, or positive result for ordering.

Opening prompt

Two separate new String("sun") objects have the same text. What do == and equals report?

Worked example

String a = new String("sun");
String b = new String("sun");
boolean same = a.equals(b);
int order = "ant".compareTo("bee");

same is true because the character sequences match. order is negative because "ant" precedes "bee". Ordering code should test the sign, not assume every nonzero result is 1 or -1.

Practice

Predict the String Output Lineup before running it. Repair sameText and order in StringRelations. Include equal text stored in separate objects.

Common error

String literals may share objects. That can make an incorrect == test appear to work.

Exit check

What does a compareTo result of zero tell you? Does it prove two variables refer to the same object?

Turn in

StringRelations checks; corrected Lineup answers; explain immutability.
