ListTraversal and safe removal

Remove list elements without skipping shifted values.

Open slidesDaily assignmentDownload notes

Key ideas

  • Removing an element shifts later elements one position left.
  • A forward loop must reconsider the same index after removal.
  • A backward loop leaves unvisited lower indexes in place.

Opening prompt

After removing index 0 from ["", "", "x"], what is now at index 0?

Worked example

int i = 0;
while (i < words.size()) {
    if (words.get(i).length() == 0) {
        words.remove(i);
    } else {
        i++;
    }
}

On removal, the next unexamined value shifts into index i, so i stays unchanged. When a value remains, increment i to move past it. The loop removes adjacent empty Strings correctly.

Practice

Complete ListTraversal and ListRemoval. Trace all matches, no matches, adjacent matches, and an empty list before running the checks.

Common error

Do not structurally change an ArrayList through ordinary remove calls inside an enhanced-for traversal.

Exit check

Why does backward removal avoid skipping the next unvisited element?
