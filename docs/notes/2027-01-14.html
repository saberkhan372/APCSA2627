Weather investigation: authentic data

Apply a tested pipeline to authentic data without overstating the result.

Open slidesDaily assignmentDownload notes

Key ideas

  • Record the source, dates, location, measurement, and unit.
  • Adapt the parser to the selected source’s documented format.
  • Compare a computed result with a small hand-checked subset.

Opening prompt

A file contains 32 and 50 in Fahrenheit. What must be settled before comparing its mean with Celsius data?

Worked example

Illustrative sample, not observed weather:
Day 1: 10.0 C
Day 2: missing
Day 3: 16.0 C
Mean of available observations: 13.0 C

Only two observations contribute to the available-data mean. Treating missing as zero would produce about 8.67 C and change the meaning. Report the missing observation and the limited sample.

Practice

Use the selected cited public weather sample. Calculate one aggregate, check a small subset by hand, and state a limitation on the conclusion.

Common error

A plausible number can still describe the wrong variable, unit, time period, or population.

Exit check

Write one sentence stating exactly what your computed result describes.

Turn in

Source-cited data brief, program, two checks and a supported conclusion.

After class

20 min: finish the brief and note one missing-value assumption.
