Linear search and search contracts

Implement sequential search according to a return-value contract.

Open slidesDaily assignmentDownload notes

Key ideas

  • Sequential search examines candidates in order.
  • A first-match contract permits return as soon as a match appears.
  • A missing target needs a specified result such as -1.

Opening prompt

For [4,7,4,9], what index should a first-match search for 4 return?

Worked example

for (int i = 0; i < values.length; i++) {
    if (values[i] == target) {
        return i;
    }
}
return -1;

Every earlier position has already failed by the time a match returns. The final -1 belongs after the loop, because a failure at one position does not prove absence from later positions.

Practice

Trace and complete searches for integers and Strings. Test first, last, missing, and duplicate targets, including an empty collection if the contract permits it.

Common error

Returning -1 inside the loop after the first mismatch stops the search too soon. This example compares primitive ints. For String contents, use .equals(...) instead of == and follow the contract’s null guarantees.

Exit check

Where should the not-found return occur, and why?

Turn in

SearchLab checks for linear cases; comparison-count table.

After class

20 min: trace searches in a sorted seven-element array and record low/high/mid.
