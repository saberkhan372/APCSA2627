Activities at Lake LazyDays

Translate temperature categories into an ordered selection.

Open slidesDaily assignmentDownload notesBoolean and Short-Circuit Explorer

Key ideas

  • An if/else-if chain selects the first true branch.
  • Every threshold needs tests below, at, and above it.
  • A final else can handle all remaining allowed values.

Opening prompt

If a rule begins "temperature >= 40", what happens to 80 before a later ">= 80" branch?

Worked example

if (temperature >= 80) {
    activity = "swimming";
} else if (temperature >= 60) {
    activity = "tennis";
} else if (temperature >= 40) {
    activity = "golf";
} else {
    activity = "skiing";
}

Descending lower bounds produce four disjoint outcomes. A value of 60 reaches tennis, while 59 reaches golf. Use the original lab for any additional allowed-temperature restrictions.

Practice

Test 39, 40, 59, 60, 79, and 80. Explain why separate independent if statements can overwrite an earlier activity.

Common error

Do not duplicate lower and upper bounds mechanically when branch order already establishes a bound.

Exit check

Which two test values best expose changing >= 60 to > 60?

Turn in
