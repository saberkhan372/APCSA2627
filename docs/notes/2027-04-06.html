Return from break and diagnostic repair

Use the pre-break baseline to repair one specific weakness.

Open slidesDaily assignmentDownload notes

Key ideas

  • Retrieve a rule before reading a solution.
  • Use a counterexample to locate the exact failure.
  • Verify the repair on a new input before changing topics.

Opening prompt

For "code", predict substring(1, 3). For ["", "", "a"], predict the result of removing every empty String.

Worked example

String word = "code";
String part = word.substring(1, 3);
// Boundaries: 0 1 2 3 4
// Selected character indexes: 1 and 2

substring uses boundary positions. This simple trace checks whether the earlier misunderstanding about the excluded endpoint has actually changed.

Practice

Correct the cumulative baseline and complete one targeted method from the error log. Use this recovery lesson for unfinished core content if needed.

Common error

Reviewing an answer until it looks familiar can feel like learning without establishing independent recall.

Exit check

What new example shows that your repaired rule transfers beyond the original question?

Turn in

Updated error log; corrected method; two named review priorities.
