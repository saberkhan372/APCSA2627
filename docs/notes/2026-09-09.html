Key ideas

  • Compilation checks Java syntax and types before a program runs.
  • A name must follow identifier rules and cannot be a Java keyword.
  • n bits distinguish 2^n patterns. Main memory such as RAM is volatile.

Opening prompt

How many bits distinguish 20 possible labels? Are total2 and 2total both valid identifiers?

Worked example

public static void main(String[] args) {
    System.out.println("2 + 3");
    System.out.println(2 + 3);
}

The quoted text prints literally as 2 + 3. The arithmetic expression prints 5. Both lines are syntactically valid. A compiler cannot infer that you intended different output.
