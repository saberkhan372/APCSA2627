Worked example

public int countPositive(int[] values) {
    int count = 0;
    for (int value : values) {
        if (value > 0) { count++; }
    }
    return count;
}

The method counts strictly positive elements and leaves the array unchanged. Check the signature, braces, comparison, and return value without relying on compiler feedback.
