2026 FRQ 4: GameBoard

Translate a row-based object-grid specification into a method.

Open slidesDaily assignmentDownload notes
Complete the independent attempt before using the worked review example. Your teacher supplies the selected assessment questions.

Key ideas

  • A row task fixes the row index while visiting columns.
  • Object cells require the supplied accessors and comparison rules.
  • A row aggregate and an all-same condition need different accumulators.

Opening prompt

For a row of numeric values 2, 5, 3, what state is sufficient for a sum? What extra fact would an all-same check track?

Worked review example

int total = 0;
boolean allSame = true;
for (int c = 0; c < values.length; c++) {
    total += values[c];
    if (values[c] != values[0]) { allSame = false; }
}

This original numeric example separates the sum from the consistency check and assumes a nonempty row. The GameBoard prompt uses its own object API and scoring rule.

Practice

Attempt released 2026 getPointsForRow for 23 minutes. Then test an all-same-color row and a mixed-color row against the official examples.

Common error

Resetting allSame to true after a later match erases evidence of an earlier mismatch.

Exit check

Once an all-same check finds a mismatch, can a later matching cell restore the all-same result?

Turn in

Timed method, correction and two concrete test rows.

After class

20 min: describe a linear search and its result when a target is absent.
