Data decision and weather investigation

Decide whether a dataset can answer a question responsibly.

Open slidesDaily assignmentDownload notes

Key ideas

  • A dataset’s sampling frame limits the population and time period it represents.
  • Units, missing values, and collection choices affect an analysis.
  • A permitted use and a useful result require separate justification.

Opening prompt

Can a week of noon temperatures establish whether mornings warmed over ten years?

Worked example

Question: Compare daytime temperatures this week.
Sample A: seven noon readings from one station, Celsius
Sample B: five daily highs, Fahrenheit, two missing days
Decision: define a comparable measurement before averaging.

Averages of different measurements or units are not automatically comparable. Identify the variable, unit, location, time, and missing-data convention before writing the algorithm. These samples are illustrative, not authentic observations.

Practice

Compare two non-personal datasets. Write a question, a source note, a units statement, a missing-data risk, and one limit on the conclusion.

Common error

A larger file does not remove bias if the same groups, locations, or times remain absent.

Exit check

Name one additional fact you need before using a dataset for a new purpose.

Turn in

One-page dataset brief; one defensible and one unsupported claim; checks for selected starter tasks.

After class

20 min: inspect a small teacher-provided public weather sample and label fields/units.
