Targeted review and recovery

Recover missed work and verify one targeted improvement.

Open slidesDaily assignmentDownload notes

Key ideas

  • Use the error log to choose a narrow target.
  • Recover a missed core task before adding extra practice.
  • A fresh check should require the repaired reasoning without cues.

Opening prompt

Choose the weaker of two current error-log categories and name the rule you expect to use today.

Worked example

Target: list removal
Evidence: a consecutive match was skipped
Practice: trace two adjacent matches and an all-match list
Fresh check: a new list with matches at both ends

The practice is linked to a particular failure and includes a new arrangement afterward. A useful recovery lesson establishes whether the rule now transfers.

Practice

Complete eight fresh MC items and one weak method or trace. Recover GridPath practice or unfinished core content before adding questions.

Common error

Completing more questions is not automatically progress if the same misconception remains unexplained.

Exit check

What evidence from today would persuade you that the target misconception has changed?

Turn in

Eight justified answers; one corrected independent method or trace.

After class

20 min: rehearse JQR lookup and the next mock-section pacing.
