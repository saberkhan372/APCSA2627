Shopping Cart: mutation and review

Preserve a cart’s order while removing every matching item.

Open slidesDaily assignmentDownload notes

Key ideas

  • A collection mutation must satisfy both selection and traversal rules.
  • Adjacent matches expose skipped-element bugs.
  • State the method’s side effects and any return value separately.

Opening prompt

If products at indexes 1 and 2 both match the removal rule, which index holds the second match after index 1 is removed?

Worked example

for (int i = cart.size() - 1; i >= 0; i--) {
    if (cart.get(i).getQuantity() == 0) {
        cart.remove(i);
    }
}

This original extension removes zero-quantity products while retaining the relative order of other products. Moving backward keeps the next lower unvisited index valid.

Practice

Add the planned remove-matching-items extension. Test consecutive matches, all matches, no matches, and an empty cart. Recompute the total after removal.

Common error

Do not confuse removing an Item from the list with changing a field inside that Item.

Exit check

What should happen when every item matches the removal rule?

Turn in

Final cart files, three mutation tests and a short code conference.

After class

20 min: write the removal algorithm from memory, then correct it.
