Key ideas

  • Branch order determines which condition gets the first opportunity.
  • Loop bounds come from the indexes used in the body.
  • An accumulator needs correct initialization and an update that matches the contract.

Worked review example

// After submission: independent review example
int count = 0;
for (int i = 1; i <= 7; i += 2) {
    count++;
}

The body executes four times, with i equal to 1, 3, 5, and 7. The next tested value is 9. The variable declared in the header is scoped to the loop.

Common error
