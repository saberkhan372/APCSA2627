Array algorithms and reversal checkpoint

Reverse an array in place without losing values.

Open slidesDaily assignmentDownload notes

Key ideas

  • A swap needs temporary storage for a value about to be overwritten.
  • Pair index i with length - 1 - i.
  • Each pair should be swapped once.

Opening prompt

In an array of length 5, which index pairs swap during reversal? What happens to the middle element?

Worked example

for (int i = 0; i < values.length / 2; i++) {
    int other = values.length - 1 - i;
    int saved = values[i];
    values[i] = values[other];
    values[other] = saved;
}

The loop visits only the first half, so it does not swap pairs back again. Empty and one-element arrays perform zero swaps. Odd and even lengths use the same index formula.

Practice

Finish the array toolkit and reverse actual elements. Test lengths 0, 1, 4, and 5. Compare an alias with a separately copied array.

Common error

Traversing the entire array performs each reversal twice and can restore the original order.

Exit check

Why must an in-place right shift usually travel from the right end toward the left?
