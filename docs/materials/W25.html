Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run Bicycle, then complete the starter tasks.

Eclipse and command-line setup

Predict before running

A constructor parameter and field are both named speed. What does speed = speed assign, and what syntax identifies the field?

Worked example
public Bicycle(String model, int speed) {
  this.model = model;
  this.speed = Math.max(0, speed);
}

A constructor establishes the object's first valid state. Use this when a parameter shadows a field.

public class Bicycle {
    private String model;
    private int gear;
    private int speed;

    public Bicycle(String model, int gear, int speed) {
        // TODO: initialize every field and prevent negative speed.
        this.model = "unnamed";
        this.gear = 0;
        this.speed = 0;
    }

    public String getModel() { return model; }
    public int getGear() { return gear; }
    public int getSpeed() { return speed; }

    public static void main(String[] args) {
        Bicycle bike = new Bicycle("Comet", 3, 12);
        System.out.println(bike.getModel() + " @ " + bike.getSpeed());
    }
}
