W37 · project

Match data to a question

Decide whether a data set contains the variables and coverage needed for a claim.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run DatasetFit, then complete the starter tasks.
  4. Run DatasetFitCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

Can one week of noon temperatures answer whether mornings became warmer over ten years? Name each mismatch.

Worked example
boolean usable = hasNeededVariable
    && coversPopulation
    && coversTimePeriod;

Start from the question, then inventory the data. Do not start from what is available and overclaim.

Project tasks

  1. Name the claim

    Underline population, variable, and time span.

    Check: Three requirements are visible.

  2. Implement fit

    Require all three coverage conditions.

    Check: Truth-table checks pass.

  3. Classify a mismatch

    Return variable, population, time, or usable.

    Check: Scenario checks pass.

  4. Limit a conclusion

    Rewrite one overclaim to match the data.

    Check: Claim scope shrinks to evidence.

AP transfer

List the minimum variables and sampling frame needed to study whether travel time affects first-period attendance at your school.
