Predict before running

A 14-year-old is with an adult but has no pass. Evaluate age >= 16 || (withAdult && hasPass) one operator at a time.

Worked example
boolean mayEnter = age >= 16 || (withAdult && hasPass);

Translate the English rule into named pieces before compressing it. Parentheses communicate structure even when precedence would produce the same result.

Project tasks

  1. Run and annotate

    Run the baseline; underline the two independent ways to enter.

    Check: Explain the parentheses in plain language.

  2. Order ticket groups

    Handle invalid ages, children, seniors, students, then regular admission.

    Check: Boundary checks at 12 and 65 pass.

  3. Implement mayEnter

    Translate the exact rule without adding unrelated conditions.

    Check: All three entry checks pass.

  4. Challenge the grouping

    Temporarily remove the parentheses and explain whether Java changes the value.

    Check: Restore the clearest form before finishing.

AP transfer

Write a single Boolean expression for: a player qualifies if score is at least 80, or if score is at least 70 and attendance is at least 95. Then test score 75 with attendance 94 and 95.
