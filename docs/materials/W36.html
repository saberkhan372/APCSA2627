Audit a data decision

Identify a data-use risk and encode a transparent consent rule.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run DataConsent, then complete the starter tasks.
  4. Run DataConsentCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

A fitness app collected location to draw a route. Can it automatically reuse that data to train an advertising model because the user agreed to location collection?

Worked example
return consented
    && statedPurpose.equals(requestedPurpose)
    && !containsSensitiveData;

Technical correctness does not settle an ethical question. Make assumptions visible and test whose interests the rule protects.

Project tasks

  1. Read the scenario

    Name the collector, subject, stated purpose, and requested use.

    Check: All four roles are explicit.

  2. Implement same-purpose use

    Require consent and matching purpose.

    Check: Purpose checks pass.

  3. Handle sensitivity

    Reject sensitive reuse in this simplified policy.

    Check: Sensitive-data checks pass.

  4. Write the tradeoff

    Name one benefit, one harm, and missing evidence.

    Check: The analysis is not only an opinion.

AP transfer

A school predicts course success from attendance and device-use data. Name one stakeholder, one possible benefit, one possible harm, and one additional fact needed before deployment.
