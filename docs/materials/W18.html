Build and test String algorithms

Accumulate a new String and manage an index that sometimes advances twice.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run StringAlgorithms, then complete the starter tasks.
  4. Run StringAlgorithmsCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

How many non-overlapping aa pairs are in aaaa? Commit to an answer and mark which characters each pair uses.

Project tasks

  1. Define the invariant

    Complete: result contains every processed character except...

    Check: The sentence matches the specification.

  2. Remove a character

    Build and return a new String; do not mutate the original.

    Check: Typical, missing, and empty checks pass.

  3. Count non-overlapping pairs

    Use a while loop and advance by two after a match.

    Check: Pair and short-String checks pass.

  4. Write an original test

    Choose a case that distinguishes overlapping from non-overlapping counting.

    Check: Predict, run, and record the result.

AP transfer

Write a method that returns a String containing only the digits from its parameter. Explain what the accumulator contains after i characters have been processed.

Explain your work

When did your loop advance by two, and what bug would advancing by one create?
