Build a one-pass String algorithm

Traverse one-character substrings with a safe bound and maintain a meaningful accumulator.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run LetterAlgorithms, then complete the starter tasks.
  4. Run LetterAlgorithmsCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

For a String of length 6, list every i used by substring(i, i + 1). What happens if the loop condition is i <= length?

Worked example
int count = 0;
for (int i = 0; i < text.length(); i++) {
  if (text.substring(i, i + 1).equals(target)) {
    count++;
  }
}

State the accumulator meaning before coding. The loop bound then follows from the one-character substring call.

Project tasks

  1. State the invariant

    Complete: count equals the matches among...

    Check: The statement names the processed prefix.

  2. Count safely

    Implement countLetter with one-character substrings.

    Check: Repeated, missing, and empty cases pass.

  3. Build a new String

    Implement removeLetter without attempting to mutate text.

    Check: Removal and unchanged cases pass.

  4. Design an edge case

    Add one case involving the first or final character.

    Check: Prediction and actual result are recorded.

AP transfer

Write a method body that returns a String containing only uppercase A characters from its parameter. State what the accumulator means after each iteration.

Explain your work

How did the substring call determine the loop's safe final value?
