Negation repair shop

Diagnose incorrect compound negations using counterexamples.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run Eligibility, then complete the starter tasks.
  4. Run EligibilityCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

Why is day != 1 || day != 7 always true? Find the value of day that you think should make it false and evaluate both comparisons.

Worked example
// not Sunday AND not Saturday
return day != 1 && day != 7;

Start with the input the method is supposed to reject. Trace the actual expression before changing an operator.

Project tasks

  1. Reproduce the bug

    Run the unchanged starter and trace notWeekend(7).

    Check: Record the wrong true result.

  2. Repair the range

    Return true only below 0 or above 100.

    Check: Four score checks pass.

  3. Apply De Morgan

    Negate submitted && signed without an outer !.

    Check: Both requirement checks pass.

  4. Repair notWeekend

    Change the smallest possible piece and justify it.

    Check: Saturday and Wednesday checks pass.

        // Repair this incorrect condition.
