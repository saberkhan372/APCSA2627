Eclipse and command-line setup

Predict before running

Why must an average method track both total and count rather than divide by the number of lines in the file?

Worked example
if (parts[0].equals(target)) {
  total += Double.parseDouble(parts[2]);
  count++;
}

A conditional average is two synchronized accumulators. Dividing by the wrong count produces plausible but incorrect output.

Project tasks

  1. Trace one file

    Mark matching and nonmatching rows.

    Check: Count includes only target station.

  2. Parse values

    Split and parse station,value.

    Check: Decimal checks pass.

  3. Compute average

    Update total and count together.

    Check: Mixed-station average passes.

  4. Handle no matches

    Follow the stated zero-result contract.

    Check: No-match check passes.
