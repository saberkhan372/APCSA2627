Scan a String safely

Traverse every valid one-character substring without crossing a boundary.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run StringScan, then complete the starter tasks.
  4. Run StringScanCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

For a String of length 6, list every legal i for substring(i, i + 1). What value of i would fail?

Worked example
for (int i = 0; i < text.length(); i++) {
  String current = text.substring(i, i + 1);
  // inspect current
}

The end index is excluded, so i + 1 may equal length even though i may not.

Project tasks

  1. Mark the bounds

    Write the first and last substring calls for banana.

    Check: First is (0,1); last is (5,6).

  2. Count matches

    Increment only when the one-character substring equals target.

    Check: Repeated and empty cases pass.

  3. Return the first index

    Return immediately on the first match; return -1 after the loop.

    Check: First, middle, and missing cases pass.

  4. Add a final-position test

    Test a target at text.length() - 1.

    Check: Prediction matches the returned index.

AP transfer

Write a method body that returns the number of uppercase A characters in a String. Use only methods on the Java Quick Reference and state the safe loop bound.

Explain your work

Why may a substring end index equal length when a character index may not?
