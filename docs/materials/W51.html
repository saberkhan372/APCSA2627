Predict before running

Why does incrementing i immediately after remove(i) skip the element that shifted into i?

Worked example
int i = 0;
while (i < values.size()) {
  if (values.get(i) < 0) values.remove(i);
  else i++;
}

Forward with a conditional increment and backward traversal are both valid. Choose from the contract and explain the invariant.
