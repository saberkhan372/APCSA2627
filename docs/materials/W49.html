Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.

Predict before running

After list.remove(1), what happens to the old elements at indexes 2 and later?

Worked example
Integer first = list.remove(0);
list.add(first);

Trace both contents and indexes after every mutating call. Method syntax is easy; index movement causes the errors.

Project tasks

  1. Trace five calls

    Check: Indexes relabeled every row.

  3. Replace middle

    Check: Odd-length check passes.

  4. Build the method table

    Record return value and size effect.

    Check: Five methods exact.
