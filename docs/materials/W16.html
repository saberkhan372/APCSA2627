Eclipse and command-line setup

Predict before running

For values 1, 3, 5, 7 produced by a loop, what is the next loop-control value after the final body execution? Why does that value not print?

Worked example
int sum = 0;
int value = 1;
while (value <= 5) {
  sum += value;
  value++;
}

A trace table needs a row for the failed condition. Otherwise students often confuse the last body value with the final variable value.

Project tasks

  1. Trace first

    Trace sumTo(3) on paper, including the failed condition.

    Check: Final row shows value 4 and sum 6.

  2. Implement sumTo

    Use a while loop and honor n >= 0.

    Check: Empty and five-value checks pass.

  3. Implement countBy

    Use an inclusive for loop with a positive step.

    Check: Three count checks pass.

  4. Compare forms

    Identify initialization, test, body, and update in both loops.

    Check: Explain which form makes the update easiest to see.

AP transfer

Without running code, give the output and final value of i for: for (int i = 2; i <= 11; i += 3). Then state how many times the body executes.
