Create and index arrays safely

Create arrays, use valid indexes, and distinguish array length from String length and ArrayList size.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run ArrayAccess, then complete the starter tasks.
  4. Run ArrayAccessCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

For int[] values = new int[5], what is the last valid index, and what exception occurs at values[5]?

Worked example
int last = values[values.length - 1];

Arrays use the public field .length. Strings use .length(); ArrayList uses .size().

Project tasks

  1. Mark the boundary

    List every valid index for length five.

    Check: 0 through 4.

  2. Implement first and last

    Return endpoints without constants.

    Check: Empty-array contract and normal checks pass.

  3. Replace one element

    Use an index only after validating it.

    Check: Valid changes; invalid request ignored.

  4. Build the syntax table

    Compare array, String, and ArrayList counts.

    Check: All three forms exact.
