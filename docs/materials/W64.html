Trace recursion without writing it

Identify base cases, recursive calls, and return values while unwinding.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run RecursionTrace, then complete the starter tasks.
  4. Run RecursionTraceCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

For sumTo(3), list calls on the way down and returned values on the way back up.

Worked example
public static int sumTo(int n) {
  if (n == 0) return 0;
  return n + sumTo(n - 1);
}

Separate call order from return order. The AP task is to analyze recursive code, not invent it from scratch.

Project tasks

  1. Trace down

    List parameters until the base case.

    Check: Argument moves toward stopping.

  2. Trace up

    Record each returned value.

    Check: Pending operation applied once.

  3. Predict two methods

    Commit before running.

    Check: Predictions saved.

  4. Diagnose nontermination

public class RecursionTrace {
    public static int sumTo(int n) {
        if (n == 0) return 0;
        return n + sumTo(n - 1);
    }

    public static String reverseDigits(int n) {
        if (n < 10) return String.valueOf(n);
        return (n % 10) + reverseDigits(n / 10);
    }

    public static void main(String[] args) {
        System.out.println(sumTo(4));
        System.out.println(reverseDigits(123));
    }
}
