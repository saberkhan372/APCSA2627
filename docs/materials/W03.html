Control a random range

Use Math methods and transform a sample in [0.0, 1.0) into an inclusive integer range.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run DiceLab, then complete the starter tasks.
  4. Run DiceLabCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

For min 20 and max 25, why is the multiplier max - min + 1 rather than max - min? Name every possible integer result.

Worked example
int value = (int)(Math.random() * (max - min + 1)) + min;

Keep the transformation in a separate method that accepts a known sample; deterministic inputs make the range arithmetic testable.

Project tasks

  1. State the preconditions

    Document min <= max and 0.0 <= sample < 1.0.

    Check: Both preconditions appear beside the correct methods.

  2. Scale known samples

    Implement scaleSample before calling Math.random.

    Check: Minimum, middle, and near-one checks pass.

  3. Wrap Math.random

    Make roll call scaleSample with Math.random().

    Check: Repeated rolls remain within the requested range.

  4. Explain the interval

    Write why 1.0 is excluded from Math.random.

    Check: The explanation connects exclusion to max + 1 never occurring.

AP transfer

Write one expression for an integer from -3 through 4 inclusive. Annotate the bucket count and the final shift.

Explain your work

Which part of the formula controls the number of outcomes, and which part controls the first outcome?
