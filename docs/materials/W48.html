Cross the wrapper boundary

Use Integer and Double values where collections require objects.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run WrapperLab, then complete the starter tasks.
  4. Run WrapperLabCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

Why can ArrayList<Integer> store 7 even though 7 is an int primitive?

Worked example
Integer boxed = 7;
int primitive = boxed;
int parsed = Integer.parseInt("42");

Do not confuse new Integer values with parsing Strings. The AP subset uses Integer and Double as collection element types.
