Trace references and aliases

Distinguish primitive copies from object aliases and predict mutations through shared references.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run AliasingLab, then complete the starter tasks.
  4. Run AliasingCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

After Player b = a; and b.addScore(5);, what score is visible through a? Draw the number of objects and reference arrows before answering.

Worked example
Player a = new Player("Ada", 0);
Player b = a;

b.addScore(5);
System.out.println(a.getScore()); // 5

Java is pass-by-value: for an object variable, the copied value is a reference. That is why another method can reach and mutate the same object.

Project tasks

  1. Trace separate objects

    Draw two objects created by two new expressions.

    Check: sameObject reports false.

  2. Create an alias

    Assign one Player variable to another without calling new.

    Check: sameObject reports true.

  3. Mutate through the alias

    Change score through one name and return the score through the other.

    Check: Both mutation checks pass.

  4. Preserve a primitive copy

    Contrast int assignment with Player assignment in TRACE.md.

    Check: The primitive values diverge after one variable changes.

AP transfer

Trace a method that receives a Player parameter, assigns it to a local variable, and changes its score. Explain precisely what value is passed and why the caller observes the mutation.

Explain your work

Read starter: Player.java
public class Player {
    private String name;
    private int score;

    public Player(String startName, int startScore) {
        name = startName;
        score = startScore;
    }

    public String getName() {
        return name;
    }

    public int getScore() {
        return score;
    }

    public void addScore(int amount) {
        score += amount;
    }
}
