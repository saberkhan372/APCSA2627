Eclipse and command-line setup

Predict before running

Three Ticket objects are created. How many copies of nextId exist if it is static, and how many if it is an instance variable?

Worked example
private static int nextId = 1;
private int id;

public Ticket() {
  id = nextId;
  nextId++;
}

Static belongs to the class. Use it for genuinely shared facts, not merely to make instance access convenient.
