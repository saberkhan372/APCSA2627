Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run ArrayAlgorithms, then complete the starter tasks.
  4. Run ArrayAlgorithmsCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

Why is int min = 0 incorrect for an array containing only positive values? What initialization uses actual data?

Worked example
int min = values[0];
for (int value : values) {
  if (value < min) min = value;
}

Each standard algorithm differs mainly in its accumulator and update rule. Preconditions determine safe initialization.

Project tasks

  1. State preconditions

    Mark which methods require nonempty input.

    Check: Minimum does; count does not.

  2. Implement minimum

    Initialize from data.

    Check: Positive and negative arrays pass.

  3. Count a target

    Visit every value.

    Check: Absent and repeated targets pass.

  4. Name the pattern

    Identify accumulator and update for five algorithms.

    Check: Each contract maps to a pattern.
