Index a String safely

Use length, substring, and indexOf while reasoning explicitly about inclusive and exclusive bounds.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run WordTools, then complete the starter tasks.
  4. Run WordToolsCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

For computer, mark the characters selected by substring(2, 5). Why may the end index equal length even though a character index may not?

Worked example
int space = text.indexOf(" ");
if (space == -1) {
  return text;
}
return text.substring(0, space);

String methods return new values because Strings are immutable. Every indexOf result must be interpreted before it is reused as an index.

Project tasks

  1. Build an index row

    Write indices under every character in AP CS A.

    Check: The last index is length - 1.

  2. Handle a missing space

    Implement firstWord without throwing when indexOf returns -1.

    Check: Phrase and one-word checks pass.

  3. Validate slice bounds

    Return invalid for negative, reversed, or too-large boundaries.

    Check: All boundary checks pass.

  4. Test the empty String

    Predict and run firstWord on an empty String.

    Check: The result is empty and no exception occurs.

AP transfer

For a String of length n, state the legal values of start and end in substring(start, end), including the zero-length cases. Then trace substring(1, 1).

Explain your work

What does -1 mean when returned by indexOf, and why is it dangerous to pass directly to substring?
