Chapter 1 Lab Exercise 5: compiler errors

Compiler-error practice

Original practice for the Chapter 1 skills. Keep the already-posted Lab Exercise 5 and quiz submission instructions; this activity adds no retrospective submission.

Download Java starter Download practice instructions

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
  1. Save the baseline as Hello.java, compile it, and run it. Record the filename, public class name, main header, and exact output.
  2. Predict the effect of deleting the print statement’s semicolon. Make only that change, compile, record the first error, and restore the baseline.
  3. Repeat with a missing closing quotation mark, then with println changed to Println. Restore the baseline between experiments.
  4. Change only the greeting text. Explain the difference between code that cannot compile and code that runs but prints an unintended message.
  5. For each experiment, record the edit, your prediction, whether compilation succeeded, the observed message/output, and the repair.
Check after predicting
  • The restored baseline compiles and prints Hello, Java! on one line.
  • Each experiment changes only one feature, so your explanation identifies a cause.
