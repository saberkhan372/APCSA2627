Eclipse and command-line setup

Predict before running

Predict the value and type of 7 / 2, 7 / 2.0, and (double) 7 / 2. Which operand changes the operation?

Worked example
int total = 7;
int people = 2;

System.out.println(total / people);          // 3
System.out.println((double) total / people); // 3.5

Java decides the operation from operand types. The destination variable cannot restore a fractional part that integer division already removed.

Project tasks

  1. Predict before editing

    Record the baseline values and types for each method.

    Check: Every prediction names both value and type.

  2. Repair average

    Change one operand so average keeps its fractional part.

    Check: Typical and exact-average checks pass.

  3. Separate cast and remainder

    Implement wholePart and remainder without mixing their meanings.

    Check: Positive and boundary checks pass.

  4. Explain assignment conversion

    Explain why double x = 7 / 2 stores 3.0.

    Check: The explanation names evaluation before assignment.
