Turn pixel position into row and column

Create and access a rectangular 2D array using row-column coordinates.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run GridBridge, then complete the starter tasks.
  4. Run GridBridgeCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

With 100-pixel cells, what column contains x = 349? What happens at x = 400 in a four-column grid?

Worked example
int row = y / cellSize;
int col = x / cellSize;
return grid[row][col];

A 2D array is an array of rows. grid.length counts rows; grid[0].length counts columns when at least one row exists.

Project tasks

  1. Map positions

    Convert four pixel coordinates by hand.

    Check: Quotients match row/column.

  2. Implement row/column

    Use integer division.

    Check: Interior coordinates pass.

  3. Guard the edge

    Reject negative and outside positions.

    Check: Boundary checks pass.

  4. Label dimensions

    State row and column counts.

    Check: length expressions exact.

AP transfer

Write a method that returns true when row and col are valid for a nonempty rectangular int[][] grid.
