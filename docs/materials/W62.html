Predict before running

Binary search runs on [8,2,9,1]. Is a -1 result evidence that the target is absent? Why or why not?

Worked example
while (low <= high) {
  int mid = (low + high) / 2;
  if (values[mid] == target) return mid;
  if (values[mid] < target) low = mid + 1;
  else high = mid - 1;
}

Sequential search needs no order. Binary search is faster only when its sorted precondition holds.

Project tasks

    Check: First/middle/last/miss pass.

  3. Compare contracts

    State input requirement and worst-case idea.

    Check: Sorted precondition explicit.

  4. Test duplicate values

    Explain acceptable returned index.

    Check: Any target index meets contract.
