Nested iteration

Assign one responsibility to each loop and predict total executions.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run PatternLab, then complete the starter tasks.
  4. Run PatternLabCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

In a five-row staircase, what does the outer loop control? What do the two inner loops control? Answer without writing code.

Worked example
for (int row = 0; row < size; row++) {
  for (int dash = 0; dash < row; dash++) {
    result += "-";
  }
  for (int star = row; star < size; star++) {
    result += "*";
  }
}

Name loops by purpose, not i/j/k, while designing. The variable names expose the output relationship.

Project tasks

  1. Match loops to output

    Annotate which loop controls rows, dashes, and stars.

    Check: Every printed character has one responsible loop.

  2. Build the staircase

    Return exact newlines without adding one after the final row.

    Check: Size 1 and size 3 checks pass.

  3. Count factor pairs

    Use a <= b so symmetric pairs are not counted twice.

    Check: Limit 2 and limit 5 checks pass.

  4. Count executions

    For size 5, total the two inner-loop body counts.

    Check: The two totals sum to 25 character writes.

AP transfer

For nested loops with row from 1 through 4 and col from row through 4, list the number of inner executions per row and the total. Do not run code.
