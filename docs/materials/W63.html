Trace sorting invariants

Identify the sorted region in selection and insertion sort and compare their moves.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run SortTrace, then complete the starter tasks.
  4. Run SortTraceCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

After the first complete selection-sort pass on [4,2,3,1], which value is fixed and at what index?

Worked example
int minIndex = start;
for (int j = start + 1; j < values.length; j++) {
  if (values[j] < values[minIndex]) minIndex = j;
}
swap(values, start, minIndex);

Trace regions, not just values: sorted, current candidate, and unexamined. Merge sort is compared conceptually; recursion writing is not required.

Project tasks

  1. Trace one pass

    Mark minIndex after each comparison.

    Check: Final minimum correct.

  2. Repair selection pass

    Swap once after scanning.

    Check: Normal and duplicate checks pass.

  3. Trace insertion

    Show the sorted prefix and shifted values.

    Check: One insertion pass correct.

  4. Compare moves

    State selection swap versus insertion shift.

    Check: Invariants distinguished.
