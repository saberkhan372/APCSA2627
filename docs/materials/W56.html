W56 · project

Build row and column algorithms

Compute row sums, scan a column, and locate a target in a 2D array.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run GridAlgorithms, then complete the starter tasks.
  4. Run GridAlgorithmsCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

For rowSum(grid, r), which index changes and which stays fixed? Reverse the answer for scanning column c.

Worked example
int total = 0;
for (int col = 0; col < grid[row].length; col++) {
  total += grid[row][col];
}

Name the fixed index before writing the loop. Many 2D errors are row/column role swaps, not nested-loop errors.

Project tasks

  1. Mark fixed/changing

    Annotate row sum and column scan.

    Check: Roles correct.

  2. Implement rowSum

    Traverse one selected row.

    Check: First/last rows pass.

  3. Implement columnContains

    Traverse rows at one column.

    Check: Present/absent pass.

  4. Locate a target

    Return row-major first coordinate.

    Check: Tie order documented.

AP transfer

Write code that returns the number of negative values in column c of a rectangular int[][] grid.

Explain your work
