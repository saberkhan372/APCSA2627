Prove a Boolean equivalence

Use a truth table to prove two Boolean expressions equivalent.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run BooleanLab, then complete the starter tasks.
  4. Run BooleanLabCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

Negate !(hasBadge && hasCode) without putting ! in front of parentheses. Which operator changes, and why?

Worked example
!(a && b) == (!a || !b)
!(a || b) == (!a && !b)

Move the negation inward, negate each condition, and switch && with || or || with &&.

Project tasks

  1. Build the truth table

    List all four combinations of a and b before coding.

    Check: Both expressions match on every row.

  2. Implement access

    A badge or staff status is required, and lockdown overrides both.

    Check: Four access checks pass.

  3. Implement the proof

    Return whether the two De Morgan forms match for the supplied row.

    Check: All four equivalence checks pass.

  4. State the transformation

    Write the three moves used to push ! inward.

    Check: Negate pieces, switch operator, remove outer !.

AP transfer

Rewrite !(score >= 70 && submitted) without an outer negation. Then explain what the rewritten condition means in plain language.

Explain your work

Which truth-table row would most quickly expose a failure to switch the operator?
