Two Meanings of Plus

Addition and concatenation practice

Original course practice for predicting Java output. Write all six predictions before running the program.

Download Java starter Download practice instructions

public class PlusPractice {
    public static void main(String[] args) {
        int a = 7;
        int b = 2;
        System.out.println("Total: " + a + b);
        System.out.println("Total: " + (a + b));
        System.out.println(a + b + " total");
        System.out.println(a / b);
        System.out.println((double) a / b);
        System.out.println((double) (a / b));
    }
}
  1. For each print statement, predict the exact output and label each operation as arithmetic or String concatenation.
  2. Run the program. Beside every mismatch, write the first operation you evaluated incorrectly.
  3. Explain why the parentheses in the second statement change the result and why the casts in the last two statements are different.
  4. Change a to 9 and b to 4. Predict all six outputs again before running.
Check after predicting
  • With a = 7 and b = 2, the first two lines are Total: 72 and Total: 9.
  • With a = 9 and b = 4, casting before division gives 2.25; casting the integer quotient afterward gives 2.0.

Evidence

A six-row prediction/observation table, two causal explanations, and your fresh predictions for the second input pair.
