Predict before running

When shifting elements one position right in the same array, why must traversal start at the right end?

Worked example
for (int i = values.length - 1; i > 0; i--) {
  values[i] = values[i - 1];
}

For in-place algorithms, trace which values are still needed. Traversal direction is part of correctness.

Project tasks

  1. Reproduce overwrite

    Trace [1,2,3,4] left to right.

    Check: Array becomes repeated ones.

  2. Reverse direction

    Repair shiftRight.

    Check: All original sources preserved.

  3. Insert a value

    Shift then write index zero.

    Check: Insert checks pass.

  4. Draw the invariant

    Mark processed and unprocessed regions.

    Check: Unprocessed sources remain intact.
