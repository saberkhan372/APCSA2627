Predict before running

For value 0, which branch must be tested first so that zero is not classified as even? Explain before running code.

Worked example
if (value < 0) {
  return "negative";
} else if (value == 0) {
  return "zero";
} else if (value % 2 == 0) {
  return "even";
} else {
  return "odd";
}

An if/else-if chain stops at the first true condition. Put exceptional and boundary cases before broader categories.

Project tasks

  1. Run the unchanged baseline

    Open the folder and run DecisionAudit before editing.

    Check: Record the three baseline lines.

  2. Complete classify

    Return negative, zero, even, or odd in the required order.

    Check: Run the check class; four classification checks pass.

  3. Complete inRange

    Include both endpoints and honor the stated precondition.

    Check: The low-endpoint and above-high checks pass.

  4. Add a boundary test

    In main, add one call at a boundary not already printed.

    Check: Predict before running and compare the result.
