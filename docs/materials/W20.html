Count executions, not milliseconds

Determine informal runtime by counting loop-body executions.

Complete the tasks named in your daily assignment. This page contains the full project.

Download starter + checks

Run the project

  1. Unzip into its own project folder. If you have already started this project, continue your existing working copy.
  2. Compile all Java files together. Keep any data file in the project folder.
  3. Run RuntimeLab, then complete the starter tasks.
  4. Run RuntimeLabCheck and explain any failing case. Do not change the check file.

Eclipse and command-line setup

Predict before running

When n doubles from 5 to 10, predict how linearCount and squareCount change. Give counts, not elapsed time.

Worked example
for (int row = 0; row < n; row++) {
  for (int col = 0; col < n; col++) {
    count++;
  }
}

The AP task is informal counting and comparison. Hardware timing adds noise and answers a different question.

Project tasks

  1. Predict n = 5

    Predict all three counts before editing.

    Check: Predictions are 5, 15, and 25.

  2. Implement each shape

    Write loops whose counters measure the intended work.

    Check: All six checks pass.

  3. Compare n = 5 and n = 10

    Record how each count changes.

    Check: Linear doubles; square quadruples.

  4. Name the scale

    Label the three methods linear, triangular/quadratic-scale, or quadratic.

    Check: Labels are justified by counts.

AP transfer

A loop runs n times. Inside it, another loop always runs 8 times. If n doubles, by what factor does the total body count change? Explain without using formal Big-O notation.
