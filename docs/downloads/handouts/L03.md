## Tasks

1. Complete the two calculations. Use multiplication for the square; Java’s ^ operator does not mean exponentiation.

2. Predict area and circumference for radii 1 and 3, using the supplied PI constant. Then run both cases.

3. Test radius 0 and one fractional radius. Explain why radius and the results use double.

4. Record each variable’s type and the unit of each result: square units for area and units for circumference.
