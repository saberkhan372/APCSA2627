# GridTraversal and row/column sums

February 9, 2027 · 75 minutes

## Learning goal

Traverse rows and columns using the dimension that changes.

## Key ideas

- A row traversal holds the row fixed and changes the column.

- A column traversal holds the column fixed and changes the row.

- A whole-grid traversal needs one loop per dimension.

## Opening prompt

For {{1,2,3},{4,5,6}}, what are row 1’s sum and column 2’s sum?

## Worked example

```
int total = 0;
for (int row = 0; row < grid.length; row++) {
    total += grid[row][column];
}
```

The variable column stays fixed while row visits every row. This assumes column is valid in each visited row. It differs from a row sum, where the changing index is the column.

## Practice

Complete rowSum, columnSum, and a search that returns as soon as its contract permits. Compare row-major and column-major visit orders on a 2-by-3 grid.

## Common error

Using grid.length as both loop bounds is only accidentally safe for square grids.

## Exit check

For a row sum at row r, which index stays fixed and which bound controls the loop?

## Assignment

Traverse a nonsquare grid in both orders, then implement row sums, column sums and a search with early return. Explain every loop bound.
