# Timed FRQ pair

April 20, 2027 · 75 minutes

## Learning goal

Manage a timed pair of method and list responses.

## Key ideas

- Convert each contract into a short implementation plan.

- Allocate time to both responses before polishing either.

- Reserve a final pass for bounds, return values, and required side effects.

## Opening prompt

Label the response areas for the fresh Methods/Control and ArrayList pair and confirm the 45-minute total.

## Worked example — after the independent attempt

```
After submission, review each response:
Signature matches the prompt
Accumulator initialization fits allowed input
Bounds match accesses
Required return and side effects match the contract
```

A review checklist is most useful when each item points to a line of code. Apply it to the saved independent response before looking at a complete solution.

## Practice

Write the fresh pair for 45 minutes. Use 30 minutes to evaluate the specifications, identify omissions, and revise.

## Common error

Do not spend the entire independent period on a nearly complete first response while leaving the second blank.

## Exit check

Which checklist item led to a concrete change in your response?

## Assignment

Write a fresh teacher-selected Methods/Control and ArrayList pair for 45 minutes; spend 30 minutes evaluating the specification and revising.

## Turn in

Two timed responses; one fully rewritten method.

## After class

20 min: correct one unfinished response and record a pacing adjustment.
