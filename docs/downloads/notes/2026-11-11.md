# BandBooster methods and tests

November 11, 2026 · 75 minutes

## Learning goal

Implement constructors and methods that preserve object state.

## Key ideas

- A constructor establishes an object’s first valid state.

- Mutator methods update fields that persist after the call ends.

- Returning a value lets the caller decide how to use it.

## Opening prompt

After three updates of 4, 7, and 2 to an initial total of zero, what should a getter return?

## Worked example

```
Meter m = new Meter();
m.add(4);
m.add(7);
int before = m.getTotal();
m.add(2);
int after = m.getTotal();
```

before is 11 and after is 13. The getter observes state without changing it. The primitive variable before keeps its copied value even after the Meter changes.

## Practice

Finish BandBooster updateSales and its runner with fictional boosters. Test initial state, repeated updates, and independence between two instances.

## Common error

A local total inside updateSales disappears after the call. Persistent state belongs in the instance field.

## Exit check

Why does a method that only prints a total not satisfy a specification requiring an int return value?

## Assignment

Finish updateSales and a small runner with three fictional boosters. Test state before and after repeated updates; distinguish a returned value from printed output.

## Turn in

Working BandBooster class/runner; at least four predicted/actual tests.
