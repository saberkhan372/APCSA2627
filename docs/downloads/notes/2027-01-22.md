# Arrays and files checkpoint

January 22, 2027 · 75 minutes

## Learning goal

Demonstrate array and file-processing contracts independently.

## Key ideas

- Array bounds come from array length.

- A file-reading method must state the format it expects.

- Parsing, traversal, and aggregation should agree about which observations count.

## Opening prompt

Confirm the assessment’s input-format assumptions and the required return value before starting.

## Worked example — after the independent attempt

```
// After submission: unrelated trace
int[] data = {3, 6, 9};
int total = 0;
for (int i = 0; i < data.length; i++) {
    total += data[i];
}
```

The total is 18 and the loop visits indexes 0, 1, and 2. The array’s length supplies the exclusive upper bound.

## Common error

A read loop that assumes valid integer tokens should not be described as validating arbitrary file input.
