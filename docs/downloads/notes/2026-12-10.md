# ArrayAccess and Tracking Sales

December 10, 2026 · 75 minutes

## Learning goal

Create arrays and distinguish capacity, indexes, and default values.

## Key ideas

- An array’s length is fixed after creation.

- Valid indexes begin at zero and stop before length.

- A new primitive array holds default values, while an object array initially holds null references.

## Opening prompt

For new int[4], what are the initial values and the final valid index?

## Worked example

```
int[] counts = new int[4];
counts[counts.length - 1] = 7;
String[] labels = new String[2];
// counts is {0, 0, 0, 7}
// labels contains two null references
```

Array length is a field accessed as counts.length. Creating an object array creates storage for references, not a String object in every slot.

## Practice

Complete ArrayAccess. In Tracking Sales, predict the index used for each salesperson and begin a traversal that visits every element once.

## Common error

Do not use length() for an array. Strings use length(), arrays use length, and ArrayList uses size().

## Exit check
