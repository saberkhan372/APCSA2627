# ArrayTraversal and enhanced-for limits

December 14, 2026 · 75 minutes

## Learning goal

Choose indexed or enhanced-for traversal according to the operation.

## Key ideas

- Enhanced for copies each element value into a loop variable.

- Assigning that loop variable does not replace an array slot.

- Use an index when replacing elements or comparing neighbors.

## Opening prompt

Does for (int n : values) { n *= 2; } double the elements of an int array?

## Worked example

```
int[] values = {2, 5, 8};
for (int i = 0; i < values.length; i++) {
    values[i] *= 2;
}
int total = 0;
for (int n : values) { total += n; }
```

The indexed loop replaces elements with 4, 10, and 16. The enhanced-for loop reads those values and produces total 30. Different loop forms fit different tasks.

## Practice

Complete count, sum, min, and max passes. Contrast replacing a String array entry with mutating a Player reached through an array reference.

## Common error

A copied object reference can still reach the same mutable object. That does not mean assignment to the loop variable replaces the slot.

## Exit check

Which traversal fits replacing every String with its uppercase form, and why?
