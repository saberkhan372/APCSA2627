# Selection and iteration synthesis

November 3, 2026 · 75 minutes

## Learning goal

Repair a control-flow error and demonstrate transfer to a new input.

## Key ideas

- A test should distinguish the incorrect algorithm from the intended one.

- The smallest failing input often exposes the cause clearly.

- A repair needs a fresh check after the original failure passes.

## Opening prompt

A String method fails only on the last adjacent pair. Which expression or bound would you inspect first?

## Worked example

```
int matches = 0;
for (int i = 0; i + 1 < text.length(); i++) {
    if (text.substring(i, i + 1)
            .equals(text.substring(i + 1, i + 2))) {
        matches++;
    }
}
```

This example counts overlapping equal adjacent pairs. "aabb" gives 2 and "aaa" gives 2. Its contract differs from counting non-overlapping doubles.

## Practice

Finish the Feeder runner, then select Boolean logic, loop bounds, or String scans for a focused repair. Explain the repaired method before executing it.

## Common error

Do not switch between overlapping and non-overlapping interpretations while evaluating the same method.

## Exit check

Give one input that distinguishes overlapping pair counting from non-overlapping counting.

## Assignment

Finish the Feeder runner; choose the weakest of loop bounds, String scans or Boolean equivalence for focused repair. Explain a method without executing it.
