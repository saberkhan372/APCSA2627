# Final project demonstrations

May 28, 2027 · 75 minutes

## Learning goal

Demonstrate the program and explain a core method with evidence.

## Key ideas

- A demonstration should show the main requirement working.

- A code explanation connects statements to the contract.

- A new test case provides evidence of understanding beyond a rehearsed example.

## Opening prompt

What will your audience see first that proves the program meets its central requirement?

## Worked example

```
Five-minute demonstration:
State the user need and core behavior
Run the main example
Explain one important method
Handle one new test case
State a limitation honestly
```

The demonstration should prioritize a working result and an explanation the audience can follow. The new test should stay within the project’s documented contract.

## Practice

Demonstrate the project, explain a core method, and handle a new test. Use the remaining class time for revisions based on feedback.

## Common error

A polished demonstration cannot substitute for explaining the program’s behavior on a new valid input.

## Exit check

What revision will you make before the final portfolio handoff?

## Assignment

Each student demonstrates the project, explains a core method and handles one new test case. Use remaining time for revisions.

## Turn in

Project demo, explanation and final revision list.

## After class

15 min: final edits and a short learning reflection.
