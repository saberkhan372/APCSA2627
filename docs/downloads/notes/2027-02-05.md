# GridBridge: coordinates to 2D arrays

February 5, 2027 · 75 minutes

## Learning goal

Translate screen coordinates into valid row and column indexes.

## Key ideas

- A 2D array is an array whose elements are row arrays.

- In grid[row][col], the first index selects a row.

- Screen x maps to a column and screen y maps to a row when cells have uniform size.

## Opening prompt

A grid has four columns of width 100. Which column contains x = 349? Is x = 400 inside it?

## Worked example

```
int[][] grid = new int[2][3];
int cellSize = 100;
int x = 249;
int y = 150;
int row = y / cellSize;
int col = x / cellSize;
```

row is 1 and col is 2, so grid[1][2] is valid. grid.length is 2. grid[0].length is 3 when the grid has at least one row.

## Practice

Complete GridBridge with a 2-by-3 grid. Trace coordinate conversion and validate both bounds before accessing the cell.

## Common error

Testing only square grids hides swapped bounds. Negative integer division also truncates toward zero, so x = -1 needs explicit rejection.

## Exit check

Which dimension supplies the column bound for a valid row r?

## Assignment

Map Processing x/y to row/column, create a rectangular grid and trace dimensions. Use a 2-by-3 array to expose swapped bounds.

## Turn in

GridBridge checks; labeled row/column diagram; correct dimension expressions.
