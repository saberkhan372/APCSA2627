# Inventory Auditor

January 8, 2027 · 75 minutes

## Learning goal

Separate reading, parsing, and inventory decisions.

## Key ideas

- The record format determines how text becomes fields.

- Numeric text must be parsed before numeric comparisons.

- Empty-input and threshold behavior must follow an explicit contract.

## Opening prompt

A record is "pencils,4". Which part is text identifying the item, and which part must become a number?

## Worked example

```
String record = "pencils,4";
String[] fields = record.split(",");
String name = fields[0];
int quantity = Integer.parseInt(fields[1]);
boolean low = quantity < 5;
```

The parsed quantity is 4 and low is true. This isolated record illustrates the parsing step. Use the supplied InventoryAudit fixture and contract for its actual full-file format.

## Practice

Complete InventoryAudit with the packaged synthetic data. Compare token reads with complete-line reads and document behavior on an empty file.

## Common error

Comparing the Strings "12" and "4" lexicographically does not compare their numeric quantities.

## Exit check

Why should parsing and the low-stock decision be checked separately?
