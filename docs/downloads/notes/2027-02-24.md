# Binary search

February 24, 2027 · 75 minutes

## Learning goal

Trace binary search while preserving its sorted interval.

## Key ideas

- Binary search requires sorted input under the comparison used.

- The active interval contains all remaining possible positions.

- Each comparison discards the midpoint and an impossible half.

## Opening prompt

Does a failed binary search on [8,2,9,1] prove the target is absent?

## Worked example

```
int low = 0;
int high = values.length - 1;
while (low <= high) {
    int mid = low + (high - low) / 2;
    if (values[mid] == target) { return mid; }
    if (values[mid] < target) { low = mid + 1; }
    else { high = mid - 1; }
}
return -1;
```

The midpoint leaves the interval after a nonmatching comparison. That guarantees progress. An empty interval occurs when low exceeds high.

## Practice

Trace low, mid, and high while finding 14 in [2,5,8,11,14,17,20]. Then search for an absent value and a boundary target.

## Common error

Updating low to mid instead of mid + 1 can leave the same interval and prevent termination.

## Exit check

What input property makes it safe to discard half the candidates?

## Assignment

Trace iterative binary search and its sorted-input precondition. Compare comparisons with linear search; test missing and boundary targets.
