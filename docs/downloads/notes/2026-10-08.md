# LoopTrace and termination

October 8, 2026 · 75 minutes

## Learning goal

Trace a loop including its final failed condition.

## Key ideas

- A loop has initialization, a condition, a body, and an update.

- The last body value can differ from the final control-variable value.

- Zero iterations are valid when the initial condition is false.

## Opening prompt

A loop visits 1, 3, 5, and 7 while its condition is i <= 8. What value fails the next test?

## Worked example

```
int i = 1;
int total = 0;
while (i <= 8) {
    total += i;
    i += 2;
}
System.out.println(total + " " + i);
```

The accumulated sum is 16 and i finishes at 9. Include a final trace row with condition false. Declaring i before the loop makes it available afterward.

## Practice

Complete sumTo and countBy in LoopTrace. Trace countBy(1, 8, 2), then test a start value already beyond the bound.

## Common error

A variable declared in a for header is out of scope after that loop. Discuss its last trace value without pretending it can be printed outside its scope.

## Exit check

How many body executions occur for i = 2; i <= 11; i += 3?

## Assignment

Trace initialization, test, body and update. Complete sumTo and countBy in LoopTrace; compare zero/one/many iterations. Record the final trace row for countBy(1, 8, 2).
