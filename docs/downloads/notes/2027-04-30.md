# FRQ simulation: first pair

April 30, 2027 · 75 minutes

## Learning goal

Simulate the Methods/Control and Class Design portion of free response.

## Key ideas

- A supplied-class response uses the provided representation.

- A class-design response must declare the needed representation.

- Save time to check both signatures and state transitions.

## Opening prompt

Identify which of the two prompts supplies a class and which requires you to design one.

## Worked example — after the independent attempt

```
After submission, compare:
Supplied class: which members may my methods use?
New class: which private fields must I declare?
Both: what must be true before and after each call?
```

The difference is responsibility for the representation. Both tasks still require agreement among signatures, state, conditions, and returned information.

## Practice

Write the fresh Methods/Control and Class Design pair for 50 minutes. Use 25 minutes to review the contracts and revise.

## Common error

Do not spend time redefining a supplied class when only its specified methods or constructor are requested.

## Exit check

Which error came from the class representation, and which came from an individual method’s logic?

## Assignment

Use a fresh current-format Methods/Control and Class Design pair for 50 minutes, then debrief for 25 minutes.

## Turn in

Two independent FRQs and focused correction notes.

## After class

20 min: finish one correction; keep the remaining pair unseen.
