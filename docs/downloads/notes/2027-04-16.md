# FRQ 4: independent 2D transfer

April 16, 2027 · 75 minutes

## Learning goal

Choose valid neighboring cells and use helper-method contracts.

## Key ideas

- A neighbor may exist in one direction but not another at a boundary.

- Handle forced boundary choices before comparing alternatives.

- A helper call supplies only the behavior its contract promises.

## Opening prompt

At the bottom row of a grid, is a cell one row below a valid candidate?

## Worked example — after the independent attempt

```
For a nonempty rectangular grid:
Last row index = grid.length - 1
Last column index = grid[row].length - 1
Down candidate = (row + 1, col), if a lower row exists
Right candidate = (row, col + 1), if a later column exists
```

At an edge, one direction may be unavailable. If both are available, use the exact comparison and tie rule stated by the problem. Do not infer the rule from a drawing alone.
