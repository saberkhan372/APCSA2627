## Learning goal

## Key ideas

- State collection preconditions before using indexes.

- Preserve or change the input only as the contract requires.

- Connect each accumulator and update to the desired result.

## Worked example — after the independent attempt

```
// After submission: unrelated list review
int count = 0;
for (Integer value : values) {
    if (value < 0) { count++; }
}
```

This review example reads a list of non-null Integer values and counts negatives without changing the list. A mutation task would need a different traversal plan.
