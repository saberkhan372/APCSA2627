# String scan and removal algorithms

October 23, 2026 · 75 minutes

## Learning goal

Scan a String with a loop bound and an accumulator that match the task.

## Key ideas

- A one-character substring at i needs i < length().

- A two-character lookahead needs i + 1 < length().

- Non-overlapping matches advance past every character consumed.

## Opening prompt

How many non-overlapping "aa" pairs appear in "aaaa"? How many overlapping pairs?

## Worked example

```
String result = "";
for (int i = 0; i < text.length(); i++) {
    String ch = text.substring(i, i + 1);
    if (!ch.equals("x")) {
        result += ch;
    }
}
```

After i characters have been processed, result contains exactly the retained characters from that prefix. For "axxb", the final result is "ab". An empty input leaves the accumulator empty.

## Common error

Changing an index in the body and again in a for update can skip an extra character.

## Exit check
