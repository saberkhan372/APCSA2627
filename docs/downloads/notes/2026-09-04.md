# Chapter 1 launch and Eclipse setup

September 4, 2026 · 75 minutes

## Learning goal

Create and run a Java program, then explain a compiler error.

## Key ideas

- A Java application begins in its main method.

- Braces group a class and its methods. A statement usually ends with a semicolon.

- A compiler error prevents execution. Incorrect output can come from code that compiles.

## Opening prompt

What did Processing supply when you wrote setup() and draw()? What must a plain Java application supply?

## Worked example

```
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

The filename is Hello.java because the public class is Hello. The main method contains the statement that prints one line. Match each closing brace to its opening brace before changing anything.

## Practice

Run Hello. Remove one semicolon, record the first error, then restore it. Repeat with a quotation mark. Finally change only the printed text.

## Common error

Do not repair every reported error at once. One missing delimiter can produce several later messages.

## Exit check

Which change is a syntax error: deleting a closing quote or printing the wrong greeting? Explain.
