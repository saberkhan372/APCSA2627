# WrapperLab and ArrayList methods

January 20, 2027 · 75 minutes

## Learning goal

Trace wrapper conversions and the basic ArrayList methods.

## Key ideas

- ArrayList stores reference types such as Integer and String.

- Boxing and unboxing connect primitives with their wrapper types.

- List mutations can change size and shift later indexes.

## Opening prompt

Why can an ArrayList<Integer> accept the expression 7 even though int is a primitive?

## Worked example

```
ArrayList<Integer> values = new ArrayList<Integer>();
values.add(7);
values.add(0, 3);
int first = values.get(0);
values.set(1, 9);
values.remove(0);
```

The list changes from [] to [7], then [3,7], then [3,9], then [9]. first is primitive 3 after unboxing. set replaces a value without changing the list’s size.

## Practice

Complete WrapperLab and ListMethods. Trace size and indexes after add, get, set, and remove. Contrast parseInt("7") with boxing 7.

## Common error

For ArrayList<Integer>, remove(1) removes index 1. It does not mean "remove the number 1".

## Exit check

Which method changes an existing value without changing list size?

## Assignment

Contrast int with Integer, parse methods, boxing/unboxing and null. Complete ListMethods with typed ArrayList<Integer> and ArrayList<String>.
