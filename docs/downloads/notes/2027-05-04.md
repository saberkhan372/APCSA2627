# FRQ simulation: second pair

May 4, 2027 · 75 minutes

## Learning goal

Simulate ArrayList and 2D free response with precise bounds.

## Key ideas

- A list can change size, so mutation affects traversal.

- A grid method needs the correct dimension for each index.

- Required side effects are part of correctness.

## Opening prompt

Identify the allowed input shape and mutation behavior for each fresh prompt.

## Worked example — after the independent attempt

```
After submission, annotate each loop:
Changing index and its legal range
Access expression controlled by that index
Effect of removal or replacement
Condition that justifies a return
```

Connecting each bound to an actual access exposes off-by-one errors. For mutation, trace the collection immediately after the update rather than assuming indexes stayed fixed.

## Practice

Write the second FRQ pair for 40 minutes. Use 35 minutes to review these responses together with the April 30 pair.

## Common error

A square test case can conceal swapped grid dimensions. A list without consecutive matches can conceal a removal bug.

## Exit check

Give one adversarial test for each of your two responses.
