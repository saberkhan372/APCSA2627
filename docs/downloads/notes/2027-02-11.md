# Magic Squares lab, part 1

February 11, 2027 · 75 minutes

## Learning goal

Build sum helpers for a square-grid checker.

## Key ideas

- A square grid has equal row and column counts.

- A diagonal uses related row and column indexes.

- Small helpers let the checker compare equivalent quantities.

## Opening prompt

In a 3-by-3 square, which coordinates form the main diagonal and the opposite diagonal?

## Worked example

```
int diagonal = 0;
int otherDiagonal = 0;
for (int i = 0; i < square.length; i++) {
    diagonal += square[i][i];
    otherDiagonal += square[i][square.length - 1 - i];
}
```

One diagonal uses equal indexes. The other pairs i with n - 1 - i. Both loops rely on the square-grid precondition.

## Practice

Write row, column, and diagonal sum helpers. For {{8,1,6},{3,5,7},{4,9,2}}, compare each required sum with the first-row total.

## Common error

Equal sums alone do not establish a normal magic square’s distinct-value and value-range requirements. State which definition the lab asks the program to check.

## Exit check

What is the opposite-diagonal column index when row i belongs to an n-by-n square?

## Assignment

Build row/column/diagonal sum helpers and compare them with the first-row total. Use the supplied magic-square context and a deliberately broken square.

## Turn in

Core checker; two expected-result grids; bounds explanation.

## After class

20 min: add one grid that has equal rows but unequal columns.
