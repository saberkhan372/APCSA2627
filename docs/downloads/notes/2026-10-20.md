# Powers of 2 and accumulation

October 20, 2026 · 75 minutes

## Learning goal

Maintain an accumulator with a precise meaning.

## Key ideas

- A sum accumulator starts at the additive identity, zero.

- A product accumulator usually starts at the multiplicative identity, one.

- State what the accumulator represents after each iteration.

## Opening prompt

If power begins at 1 and doubles four times, what are its successive values?

## Worked example

```
int power = 1;
int sum = 0;
for (int exponent = 1; exponent <= 4; exponent++) {
    power *= 2;
    sum += power;
}
```

After each iteration, power is the current power of two and sum contains all powers added so far. The final values are 16 and 30.

## Practice

Write Powers of 2 without Math.pow. Complete the selected Loop Programs items. For an extrema task, explain how the first actual value initializes min and max.

## Common error

Starting a product at zero keeps it zero forever. Starting a minimum at zero fails for all-positive data.

## Exit check

For data 6, 9, 4, what should min start at and finish at?
