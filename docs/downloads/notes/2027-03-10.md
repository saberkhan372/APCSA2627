# Weather investigation: collections extension

March 10, 2027 · 75 minutes

## Learning goal

Choose a collection that fits an authentic-data question.

## Key ideas

- Use an array for a fixed sequence, a list for a changing sequence, or a grid for meaningful row/column structure.

- An aggregate and a filter answer different questions.

- Interpretation depends on the source and selection rules.

## Opening prompt

If two groups have 2 and 6 readings, when does averaging their means misrepresent the mean of all 8 readings?

## Worked example

```
Illustrative groups:
A: 10, 20                 mean 15
B: 30, 30, 30, 30, 30, 30 mean 30
Mean of group means: 22.5
Mean of all readings: 26.25
```

The overall total is 210 across 8 observations. Keep sums and counts so the calculation can respect the intended unit of analysis. These values are illustrative.

## Practice

Extend the authentic weather investigation with one aggregate and one filter or group comparison. Justify array, ArrayList, or 2D array and verify a small result manually.

## Common error

Using a 2D array solely because it looks more advanced can introduce meaningless grouping.

## Exit check

State the unit of analysis for your result: observations, days, weeks, or another defined group.

## Assignment

Finish authentic-data transfer if pending. Choose array, ArrayList or 2D array for a justified analysis; implement one aggregate and one filter/group comparison.

## Turn in

Source-cited investigation, justified structure choice and two manual checks.
