String Index Explorer

Characters sit in numbered boxes. substring cuts at numbered fence posts between them. Predict a call, then see exactly where Java looks, and why some calls crash.

This tool is built for basic Latin text (letters, digits, punctuation, spaces). Other symbols still follow Java's rule, one UTF-16 code unit per index, so one visible symbol may take up two boxes.
