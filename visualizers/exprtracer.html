Expression and Type Tracer

Every value in an expression has a type, and Java works one operation at a time. Watch the exact step where a fraction disappears, a number turns into text, or an int runs out of room.

Try:

Supports int, double and String; + - * / %; casts; parentheses; Math.abs, Math.pow, Math.sqrt; Integer.MAX_VALUE and Integer.MIN_VALUE. Anything else is marked “not supported here”, never as a Java error. Doubles print the way Java 19 and later print them.

No ladder here. Write the type of every intermediate value on paper, then check.
