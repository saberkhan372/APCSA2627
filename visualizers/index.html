Visualizers

Step through what Java actually does. Each tool starts with a prediction, so commit to an answer before you look. Every answer these tools give is checked against real Java.

Unit 1 · Using Objects and Methods

  • compareTo Visualizer

    Live

    Watch Java compare two Strings one index at a time, stop at the first mismatch, and fall back to length when one is a prefix of the other.

  • String Index Explorer

    Live

    Boxes for charAt, fence posts for substring, a sliding search for indexOf, and a line-by-line tracer for the WorkingWithStrings lab.

  • Expression and Type Tracer

    Live

    An expression reduces one operation at a time, with every value labeled int, double or String.

  • Memory Diagram

    Live

    Variables as arrows to objects: aliasing, null, == versus equals, the string pool, and why Strings never change.

  • Math.random Range Builder

    Live

    Scale, cast and shift one step at a time, the exact range, and how often each value comes up.

  • Output Predictor

    Live

    A console with a visible cursor: print versus println, escape sequences, and exactly what a program prints.

Unit 2 · Selection and Iteration

  • Boolean and Short-Circuit Explorer

    New

    Evaluate a condition one part at a time: skipped operands stay visibly unevaluated, a null guard works only in the right order, De Morgan equivalence, and dangling else.

  • Loop Tracer

    New

    Initialize, check, body, update: a trace table for every loop, the equivalent while loop, and a grid for nested loops.

Units 3 and 4 · Classes and Data Collections

  • Method-Call and Parameter Tracer

    Coming

    Call frames, parameters as copies, return values, and references to shared objects.

  • Recursion Call Stack

    Coming

    Calls stack up with their own parameters, stop at the base case, then return one at a time.

  • ArrayList Mutation Explorer

    Coming

    Watch later elements shift as you add and remove, and see why an index loop can skip an element.

  • Search and Sort Workbench

    Coming

    Predict the next comparison, swap or insertion, and follow binary search’s shrinking interval.

How to use them: Predict first, with a reason. Then use Explore to test your own examples. Finish with Transfer, which has no animation, to check you can do it on paper.
