# Unit 1 code task: Percent correct

Write `percentCorrect` in `Percent.java` without changing its header.

- **Returns:** the exact percentage of correct answers, from 0.0 to 100.0, not rounded. `percentCorrect(7, 8)` returns `87.5`.
- **Precondition:** `total > 0` and `0 <= correct <= total`. You do not need to handle other input.
- **Watch for:** where integer division could happen before the result becomes a double.

Predict the result for each case in `PercentCheck.java` first. Then compile both files and run `PercentCheck`.
Passing every check means your method works on those cases. It is feedback, not proof that it is correct for every input.
