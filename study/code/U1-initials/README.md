# Unit 1 code task: Initials

Write `initials` in `Initials.java` without changing its header.

- **Returns:** the first letter of each name, each followed by a period. `initials("Ada Lovelace")` returns `"A.L."`.
- **Precondition:** `fullName` contains exactly one space, which separates two non-empty names, with no spaces at the start or end. You do not need to handle other input.
- **Use:** `indexOf` and `substring`.

Predict the result for each case in `InitialsCheck.java` first. Then compile both files and run `InitialsCheck`.
Passing every check means your method works on those cases. It is feedback, not proof that it is correct for every input.
